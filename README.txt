COGNISTREAM ADVANCED DASHBOARD
================================

WHAT THIS PROJECT DOES
- Responsive developer productivity dashboard
- Working sidebar navigation: Dashboard, Flow Analytics, Developer Activity, Interruptions
- KPI cards and sample productivity charts
- Activity search and category filter
- Add activity form; new activities are saved in browser localStorage
- Export activity records to CSV
- Dark/light theme toggle
- Mobile sidebar menu

HOW TO RUN IN VS CODE
1. Extract the ZIP file.
2. Open VS Code.
3. Select File > Open Folder.
4. Choose the extracted CogniStream_Advanced folder.
5. Install the "Live Server" extension if it is not installed.
6. Right-click index.html and select "Open with Live Server".
7. Browser opens the dashboard. Click the left sidebar menu items to test pages.

IMPORTANT PROJECT NOTE
This is a front-end demo project using HTML, CSS and JavaScript. It uses sample/demo data.
It is not connected to GitHub, a real IDE, or real developer activity tracking.
For a real production system, add a backend, database, authentication and approved IDE/Git integrations.

FILES
- index.html : page structure
- style.css  : responsive design and styling
- script.js  : navigation, charts, filters, activity form, CSV export
